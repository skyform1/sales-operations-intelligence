# Phase 9: Offline executive demo and verification

Open `executive_demo.html` in a modern browser (no installation or server required). It is a standalone, responsive portfolio demonstration using the Phase 6 synthetic forecast scenario results. Change the risk scenario and quarterly target to recompute attainment and decision framing.

The existing Streamlit application remains available via `pip install -r requirements.txt && streamlit run app.py`. Streamlit has **not** been deployed or browser-tested here; this Phase 9 deliverable is an independent HTML demonstration.

**Evidence boundaries:** All data are fictional; probabilities, impacts, and risk scenarios are illustrative. This is not an empirically validated forecast, production system, or AI model. No external services or CRM data are used.
